Incident INC-2025-0412

Elevated 502s on task sync

A configuration rollout reduced the sync-worker connection pool and caused elevated errors until the fleet was restored.

Summary Timeline Impact Root cause Follow-ups

What happened

Summary

A config rollout lowered the database connection-pool limit on the sync-worker tier from 64 to 8. Normal afternoon load exhausted the pool, and the sync API returned 502s for 21.4% of requests until the config was reverted and the worker fleet cycled. No data was lost.

Causal analysis

Root cause

  1. The new sync-worker pool setting retained a local-test value of 8 instead of inheriting the global value of 64.
  2. The config linter checked the value's type but did not enforce a safe magnitude.
  3. Separate config and code pipelines made recent application deploys appear more likely, adding about 13 minutes to diagnosis.
