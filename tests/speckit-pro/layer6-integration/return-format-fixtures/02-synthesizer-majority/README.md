# Fixture 02 — Synthesizer, 2-of-3 majority branch

Fixture 01 captures the synthesizer's two-analyst disagreement branch
(no decision in Round 1). This fixture captures the **majority
branch**: all three analysts ran, two recommend JSON, and the domain
researcher dissents. The item carries no security keyword
(`Security Route: none`, every analyst `security_relevant: false`), so
the ordinary 2-of-3 rule applies and the synthesizer must emit a real
decision artifact that preserves the dissent.

Together fixtures 01 and 02 cover both decision branches of the
synthesizer's response format.
