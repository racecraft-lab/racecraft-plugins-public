## Answer

Count tokens `per-billing-period`.

## Citations

- **Source**: LLM provider billing documentation (retained fixture evidence)
  **Title**: Usage and billing

## Confidence

**Rationale**: This matches how providers bill. Per-request token records tie
usage to individual users, which makes them personal data, so aggregate counts
expose less.
