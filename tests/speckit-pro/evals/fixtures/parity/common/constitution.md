# Native Parity Fixture Constitution

## Evidence before claims

Every completion, safety, and parity claim must cite current retained native
evidence. Missing or malformed evidence blocks progress.

## Independent correctness before comparison

Each native client must satisfy the workflow requirements independently.
Cross-client similarity cannot convert an incorrect result into a pass.

## Ownership and mutation boundaries

The parent owns workflow routing and serial decisions. Workers receive exclusive
bounded ownership. Only artifacts declared by the active fixture may be created;
PR, stack-manager, and other external mutations require explicit authorization
and current prerequisites.
