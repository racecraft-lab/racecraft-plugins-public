## Available controls

The public entry point supports new layer numbers or semantic layer keys,
host/case selection, one trial by default, configurable repetitions, bounded
provider pools, explicit execution, resume, and explicitly selected retries.
Subject and shared judge work use the same Codex pool. See [README.md](README.md)
for commands and evidence semantics.

Compatible passing results are reused. Completed failures are preserved.
Changing grading alone can regrade sufficient retained evidence without a new
subject run. A change in actual runtime inputs does not qualify for that reuse.

When a complete capture proves a required output is missing or contains malformed
JSON, grading records a behavioral failure rather than an infrastructure error.
Transport errors and unsafe or unreadable captures remain invalid. Focused
verification passed 45 contract checks and 66 execution checks, including both
clients' missing-text, missing-JSON, malformed-JSON, and failure-preserving resume
paths. These are provider-free harness checks, not additional live case passes.

The isolation-checker fingerprint now follows its security-relevant source and
import dependencies instead of hashing the entire adapter module. Unrelated
judge edits therefore do not invalidate subject evidence. Moving to this new
fingerprint deliberately invalidates earlier checker receipts once; the
historical measurements above have not been rewritten as current qualification.
