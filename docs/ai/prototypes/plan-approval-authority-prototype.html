        About this demo
        
      
        No real approval authority or security qualification
        All people, machines, files, version labels, evidence, status responses, records and tasks are samples. A button proves no human presence. It cannot enroll credentials, sign data or permit real work.
        
      
        Question
        
      
        Can a reviewer understand this plan, choose for each issue, and approve the exact version? Can later checks block changed plans, lost trust or missing current status?
        
      
        Setup and use
        
      
        Open this HTML file. Read the plan in Review. Choose for each issue. Check your choices before approval. Use Implementation for separate work checks. Use Scenarios for sample cases and technical details.
        
      
        Demo state stays in memory. Closing or reloading the page loses that state. The gallery code stores only your theme preference. It requests standard fonts and has fallback fonts. This file accesses no credentials, real signer, approval service or production runner.
        
      
        What remains unproved
        
      
        This demo explores ADRs 0013 and 0015 with one sample reviewer. The signer candidate is Secure Enclave with fresh biometric or password confirmation. It remains unqualified. The model implements no signing. Protected enrollment, current-status delivery, data encoding and human verification remain unproved. Isolation on the same Mac and existing account remains unproved. No second computer is available. Transfer between machines is a demo only.
        
      
        A passed demo check shows a state change only. It proves no protected approval, secure key custody, authentic current status, rollback protection or independent enrollment. It proves no protected display, consistent host behavior or safe real task start.
        
      
        This text uses STE-inspired short sentences and consistent terms. It does not claim formal ASD-STE100 compliance or certification.
