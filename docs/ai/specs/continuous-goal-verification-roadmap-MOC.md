# Roadmap - Map of Content

Navigation map for the Continuous Goal Verification roadmap. This home note
carries two zones: a curated epics zone edited by hand, and a generated index
that `generate-spec-index` rewrites between the sentinels below.

## Epics (curated)

### Foundation

Why: Settle the host boundary on both platforms, then define the versioned
decision contract every later check consumes, before any shipped behavior
changes.

- VRFY-001 Host Boundary and Implementation-Map Spike
- VRFY-002 Versioned Decision Contract and Offline Prepare/Assess

### Records and Targets

Why: Decisions need an immutable journal to replay from, and a frozen set of
obligations to be judged against. Both are pure offline work and run in
parallel.

- VRFY-003 Additive Decision Journal and Offline Replay
- VRFY-008 Frozen Goal and Obligation Registry

### Wire

Why: The single slice that touches the provider, on Claude Code and Codex
together, default disabled, with consent and budget checks before every call.

- VRFY-004 Dual-Host Trusted-Parent Adapter with Consent, Budget, and Egress Controls

### Shadow Pilots and Phase-Boundary Verifier

Why: Insert semantic checks at three existing evidence handoffs and reconcile
the full obligation set at phase and terminal boundaries, all as annotations
that change no gate result.

- VRFY-005 Pilot: Requirement-to-Task Semantic Coverage
- VRFY-006 Pilot: Review-Fix Closure Verification with Deterministic Prerequisites
- VRFY-007 Pilot: Claim-to-Source Support Annotation
- VRFY-009 Phase-Boundary Goal-Completion Verifier

### Incremental Verification

Why: Check between boundaries only when evidence actually changed, never
re-bill identical state, and never let a late result advance state.

- VRFY-010 Change-Triggered Scheduler and Invalidation

### Advice and Calibration

Why: Show the operator exactly which obligations are unmet before a done
claim, and measure run-level false completion on frozen trajectories before
any check is promoted beyond shadow.

- VRFY-011 Premature-Stop and Redundant-Continuation Advice
- VRFY-012 Trajectory Corpus, Calibration Report, and Gated Live Evaluation
