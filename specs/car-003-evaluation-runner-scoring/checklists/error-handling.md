## Rerun Eligibility and Arm Symmetry

- [x] CHK033 - Are reruns restricted to **independently preclassified transient harness failures** only, with every other failure class ineligible? [Coverage, Spec §FR-021]
- [x] CHK034 - Are one-arm reruns prohibited, and is the prohibition expressed as impossible by construction rather than as a rule to be observed? [Clarity, Spec §FR-021]
- [x] CHK035 - Does the rerun cap count **reruns rather than attempts**, and is it prespecified per comparison pair? [Measurability, Spec §FR-021]
- [x] CHK036 - Is the post-cap outcome specified when complete evidence remains unavailable? [Completeness, Spec §FR-021]
- [x] CHK037 - Is the arm-blind preclassification **evidenced**, or only precommitted as policy? FR-021 requires classification before either arm's outcome is read and the experiment policy pins that timing, but no requirement obliges the rerun record to carry evidence that the classification actually preceded the outcome read. A pinned policy value is a precommitment, not proof it held — the same defect already corrected for cache-state isolation — so a post-hoc classification would satisfy every stated rule while being exactly the outcome-conditioned filtering the requirement exists to prevent. [Gap, Spec §FR-021]
- [x] CHK038 - Are superseded pairs required to be retained immutably and excluded only as **complete pairs**, arm-symmetrically? [Consistency, Spec §FR-021]
- [x] CHK039 - Is "exactly one terminal complete pair per assignment" stated, so a rerun cannot inflate the denominator? [Measurability, Spec §FR-021]

## Non-Qualifying Terminal States

- [x] CHK040 - Are the requirements explicit that a failed gate, tie, mixed dominance, incomplete evidence, or statistical uncertainty produces **no qualification** and never a forced weighted ranking? [Completeness, Spec §FR-019]
- [x] CHK041 - Is the prohibition on weights, price coefficients, and scalar score fields stated as a structural property of the decision bundle rather than a reporting convention? [Clarity, Spec §FR-019]
- [x] CHK042 - Is a stage that was never reached required to record `not_evaluated` rather than being omitted or defaulted to a pass? [Coverage, Spec §FR-017, §FR-018]
- [x] CHK043 - Are `no_qualification` and `inconclusive` partitioned? The terminal enumeration carries both as distinct members, but FR-019 uses the phrase "no qualification" for the umbrella non-qualifying outcome while also naming a member of that enumeration, and FR-021 says unclassifiable attrition "returns inconclusive **or** no qualification" without saying which. The frozen plan pins ties and mixed dominance to `inconclusive`, which reads as a direct contradiction of FR-019's routing of "tie, mixed dominance" to no qualification. Two conforming implementations could emit different terminal members from identical evidence, which SC-011 forbids. [Gap, Spec §FR-019, §FR-021]
- [x] CHK044 - Is `qualified` required to be structurally unreachable from a calibration partition, rather than merely disallowed by policy? [Measurability, Spec §FR-013, §FR-024]
- [x] CHK045 - Are the closed decision reasons sufficient to explain every non-qualifying terminal state, including rerun-cap exhaustion, attrition-cap excess, budget exhaustion, and reference-integrity failure? [Completeness, Spec §FR-019, §FR-032]
- [x] CHK046 - Is deterministic replay required to reconstruct the **same terminal decision**, making the terminal-state mapping a correctness property rather than a presentation choice? [Traceability, Spec §SC-011]
