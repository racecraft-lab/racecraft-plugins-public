# Security Checklist: Draft-PR Template Set (ART-002)

**Purpose**: Unit tests for the security requirements themselves — are the
obligations ART-002 inherits from `speckit-pro/artifact-gallery/SPA-CONTRACT.md`
written completely, unambiguously, and consistently enough that a port author
cannot satisfy the letter and miss the property?

**Created**: 2026-08-10

**Feature**: [spec.md](../spec.md)

**Depth**: Release gate. **Audience**: reviewer at pull-request time.

**Scope**: prohibited constructs; external references and script-literal scanning;
embedded-asset media types; fill-region placement against the contract's four
forbidden interpolation contexts; attribution agreement with the catalog.
The forward-looking half — whether a slot's placement holds for a value ART-007
writes later — is weighted hardest, because nothing downstream re-checks it.

**Result**: 40 items. 9 gaps found on the first pass, 9 remediated, 0 open.

**Note**: This checklist is generated by the `/speckit-checklist` command based on
feature context and requirements.
