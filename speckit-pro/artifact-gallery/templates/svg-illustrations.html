  • Stroke

    Neutral boxes use 1.5px borders; the active or completed step uses a 3px outline so emphasis is visible without color.

  • Labels

    Every meaningful state is written as text inside or near the shape: next, fail, success, fan-out, and fan-in.

  • Pattern

    The oldest queued job uses a diagonal pattern, so a repeated waiting state can be distinguished in monochrome.

  • Type

    Box labels use the canonical mono stack; annotations use the canonical body stack with readable system fallbacks.

  • Motion

    The illustrations are static. The only theme transition is the canonical gallery transition, covered by the reduced-motion rule.
